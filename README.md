# SpendWise Dashboard Shell## Project DescriptionSpendWise is a responsive personal budget dashboard built using HTML5 and CSS3. It provides a modern interface for viewing financial summaries, spending categories, budgets, savings, and recent transactions.This project focuses on layout and visual design. All financial information is static sample data.## Technologies Used- HTML5 for the dashboard structure.- CSS3 for styling and visual design.- CSS Grid for the overall page layout, summary cards, and category cards.- Flexbox for the header, sidebar navigation, and card contents.- CSS custom properties for a consistent color theme.- Media queries for responsive layouts.- CSS transitions for hover and keyboard-focus effects.- `prefers-color-scheme: dark` for automatic dark mode.## Project Files### 1. index.htmlContains the structure of the dashboard, including:- Sidebar navigation menu.- Dashboard header.- Financial summary cards.- Six spending category cards.- Recent transactions section.- Footer.### 2. style.cssControls the visual appearance and layout, including:- CSS variables for colors and shadows.- Grid and Flexbox layouts.- Category icons and budget progress bars.- Hover and keyboard-focus animations.- Responsive design below 768px.- Automatic dark theme based on system preferences.- Reduced-motion accessibility support.### 3. README.mdDocuments the project, technologies, file structure, and responsive design features.## Layout TechniquesCSS Grid is used for the main dashboard layout, financial summary, and category cards.Flexbox is used to arrange the sidebar navigation, header actions, card contents, and recent transactions.Absolute positioning is not used for the page layout.## Responsive DesignThe dashboard uses a media query at `max-width: 767px` to change the page to a single-column layout on smaller screens.The layout should be tested using the browser's DevTools Device Toolbar.## Card Micro-interactionsCategory cards use CSS transitions lasting 200 milliseconds. On hover or keyboard focus, cards move slightly upward and receive a shadow and border-color change.## Dark ThemeThe dashboard supports dark mode using `@media (prefers-color-scheme: dark)`. Only the CSS custom properties inside `:root` are overridden.## How to Run1. Download or clone this repository.2. Open the project folder in VS Code.3. Open `index.html` in a browser.4. Use the browser's developer tools to test responsive layouts.## LimitationsThis is a visual dashboard prototype. It does not store transactions, calculate live balances, or provide working budget-management features.## AuthorSalah Omar
